How it works

Three steps.
No manual required.

  1. 1

    Open Hop on both.

    Your Mac and your PC appear on each other’s radar, as long as they share a network.

  2. 2

    Drop a file on a device.

    Files, photos, whole folders. Drag them onto the other computer’s avatar.

  3. 3

    Accept. It’s there.

    The other side taps Accept and the files land in Downloads/Hop, at full Wi-Fi speed.

Install

Up and running
in a minute.

Hop isn’t signed by Apple or Microsoft yet, so each system asks you to confirm once. Here’s exactly what to click.

  1. Download the version for your Mac.

    Apple silicon M1, M2, M3, M4 and later Hop-mac-arm64.dmg Intel Macs with an Intel processor Hop-mac-x64.dmg

    Not sure? Open the Apple menu > About This Mac. If it says Chip: Apple M…, pick Apple silicon. If it says Processor: Intel, pick Intel.

  2. Drag Hop to Applications.

    Open the downloaded .dmg and drag the Hop icon onto the Applications folder.

  3. Let it open the first time.

    Because Hop isn’t notarized by Apple yet, macOS blocks the first launch. Clear it one of two ways:

    Option A — Terminal
    xattr -cr /Applications/Hop.app

    Paste into Terminal, press Return, then open Hop as usual.

    Option B — System Settings

    Try to open Hop once, then go to System Settings > Privacy & Security, scroll down and click Open Anyway. Confirm with your password.

  4. Allow Local Network access.

    When macOS asks whether Hop may find devices on your local network, click Allow. Missed it? Turn Hop on in System Settings > Privacy & Security > Local Network.

  1. Download and run the installer.

    Windows 10 and 11 64-bit installer Hop-windows-x64.exe

    Hop installs in a few seconds and opens on its own.

  2. Get past SmartScreen.

    If Windows says “Windows protected your PC”, click More info, then Run anyway. It appears because Hop isn’t code-signed yet.

  3. Allow it through the firewall.

    When Windows Defender Firewall asks, make sure Private networks is checked and click Allow.

  4. Set your Wi-Fi to Private.

    Windows hides your PC on Public networks. Open Settings > Network & internet > Wi-Fi, choose your network and set Network profile type to Private network.

FAQ

Questions, answered.

My computers don’t see each other. What now?
  • Same network. Both computers must be on the same Wi-Fi or wired network. A mix of Wi-Fi and Ethernet on the same router is fine.
  • Firewall. On Windows, allow Hop on Private networks and set your network profile to Private (see Install). On the Mac, allow Local Network access.
  • VPN. A VPN can route local traffic away from your network. Pause it and try again.
  • Guest Wi-Fi. Guest networks, many office networks and routers with “client isolation” or “AP isolation” stop devices from seeing each other. Use your main network.

Hop finds devices with small broadcasts on UDP port 47800, so that port must not be blocked.

Where do received files go?

Into Downloads/Hop. Click the folder name at the bottom of the Hop window to open it, or click Change to pick another folder. If a file with the same name exists, Hop keeps both.

Is it secure?

Files never leave your local network, and nothing is stored on a server. Every incoming transfer asks for your OK unless you’ve marked the sender as trusted, and you can forget trusted devices at any time.

Transfers aren’t encrypted yet. That’s fine on your home network; avoid using Hop on public Wi-Fi until encryption lands.

Why does my computer show a security warning?

Hop isn’t code-signed or notarized yet, so macOS and Windows can’t vouch for the developer. The warning appears once; the Install section shows how to get past it. The full source code is on GitHub if you’d rather build it yourself.

Is Hop free?

Yes. Hop is open source under the MIT License. No ads, no account, no tracking.
